# 📚 Atividades de Aprendizado — Git e GitHub

## 🎯 Objetivo

Desenvolver conhecimentos práticos sobre controle de versão, colaboração em projetos, gerenciamento de tarefas, automação e ferramentas de desenvolvimento do ecossistema GitHub, compreendendo também os recursos próprios do Git e suas diferenças em relação às plataformas de hospedagem.

**Repositório de estudos:** fork do repositório de [Alline Antuness](https://github.com/AllineAntuness), no contexto dos estudos da DIO.

---

## 1. 🛠️ Contribuição para projetos de terceiros

- [ ] Desenvolver um script em Python para monitoramento da conexão com a internet.
- [ ] Versionar o código utilizando Git.
- [ ] Publicar as alterações no fork pessoal.
- [ ] Criar um Pull Request propondo a incorporação do código ao repositório original.
- [ ] Acompanhar o estado do Pull Request: aberto, integrado ou fechado.
- [ ] Compreender o processo de revisão e integração de contribuições.

## 2. 💬 Criação e discussão de Issues

- [ ] Abrir uma Issue propondo conteúdo explicativo sobre programação orientada a objetos (POO) e sua diferença em relação a outros paradigmas.
- [ ] Compreender a finalidade das Issues na documentação, discussão e organização de tarefas.
- [ ] Acompanhar comentários, respostas e eventuais solicitações de esclarecimento.

## 3. 🌿 Fluxo de trabalho com Git e GitHub

- [ ] Praticar os comandos `git add`, `git commit`, `git push` e `git pull`.
- [ ] Criar, listar e alternar branches utilizando `git branch` e `git switch`.
- [ ] Compreender as diferenças entre repositórios locais e remotos.
- [ ] Utilizar `git diff` para inspecionar alterações.
- [ ] Simular conflitos de merge e praticar sua resolução.
- [ ] Experimentar forks, Pull Requests e integração de alterações.
- [ ] Compreender o funcionamento de `git fetch`, `git merge` e `git rebase`.

## 4. 🌐 Participação na comunidade open source

- [ ] Identificar projetos públicos de interesse.
- [ ] Consultar a documentação e as diretrizes de contribuição.
- [ ] Abrir uma Issue pertinente, apresentando um bug reproduzível, uma dúvida técnica ou uma sugestão fundamentada.
- [ ] Interagir com mantenedores e colaboradores de forma construtiva.
- [ ] Conhecer o processo de contribuição para projetos mantidos por terceiros.

## 5. ☁️ GitHub Codespaces e ferramentas de IA

- [ ] Criar e configurar um ambiente de desenvolvimento no GitHub Codespaces.
- [ ] Explorar as ferramentas de inteligência artificial disponíveis no ambiente.
- [ ] Gerar, revisar e testar código com auxílio de IA.
- [ ] Comparar o desenvolvimento em ambientes remotos com IDEs instaladas localmente.
- [ ] Avaliar consumo de recursos, praticidade, custos e limitações.

## 6. 📋 Gerenciamento de projetos e tarefas

- [ ] Criar um repositório para um projeto próprio.
- [ ] Explorar Issues, responsáveis, etiquetas e prazos.
- [ ] Atribuir tarefas ao próprio usuário para compreender o fluxo de gerenciamento.
- [ ] Experimentar milestones, GitHub Projects e acompanhamento do progresso.
- [ ] Relacionar tarefas às alterações realizadas no código.

## 7. 📝 Documentação e apresentação de projetos

- [ ] Elaborar um `README.md` com objetivos, funcionalidades, tecnologias e instruções de execução.
- [ ] Utilizar Markdown para estruturar a documentação.
- [ ] Criar e personalizar o README do perfil GitHub.
- [ ] Apresentar projetos relevantes, exemplos de uso e limitações.
- [ ] Registrar aprendizados e contribuições realizadas.

## 8. ⚙️ Automação com GitHub Actions

- [ ] Criar um workflow básico de integração contínua (CI).
- [ ] Automatizar verificações de sintaxe e execução de testes em Python.
- [ ] Compreender o funcionamento de eventos, jobs e steps.
- [ ] Consultar os resultados das execuções na aba **Actions**.
- [ ] Verificar como a automação pode auxiliar na qualidade do código.

## 9. 📦 Publicação e manutenção de projetos

- [ ] Organizar branches de desenvolvimento e de versões estáveis.
- [ ] Criar tags e releases para identificar versões do projeto.
- [ ] Gerenciar dependências e arquivos de configuração.
- [ ] Configurar adequadamente o `.gitignore`.
- [ ] Evitar a publicação de credenciais, arquivos `.env` e dados sensíveis.
- [ ] Compreender o versionamento semântico e a manutenção de versões.

## 10. 🐧 Git sem dependência de uma plataforma

- [ ] Compreender o Git como um sistema distribuído de controle de versões.
- [ ] Criar repositórios locais e repositórios remotos independentes do GitHub.
- [ ] Explorar a troca de alterações por SSH e arquivos patch.
- [ ] Conhecer alternativas de hospedagem, como [Codeberg](https://codeberg.org/) e [Forgejo](https://forgejo.org/).
- [ ] Distinguir os recursos nativos do Git das funcionalidades oferecidas pelas plataformas de colaboração.

## 11. 🤝 Colaboração e revisão de código

- [ ] Trabalhar com branches de funcionalidades.
- [ ] Solicitar e realizar revisões de código.
- [ ] Compreender aprovações, comentários e solicitações de alteração.
- [ ] Praticar a resolução de conflitos entre branches.
- [ ] Entender permissões de acesso e colaboração em repositórios.
- [ ] Compreender as diferenças entre contribuir por meio de um fork e trabalhar diretamente em um repositório compartilhado.

## 12. 🔐 Segurança e boas práticas

- [ ] Configurar autenticação por SSH e compreender o uso de tokens de acesso.
- [ ] Identificar arquivos e informações que não devem ser publicados.
- [ ] Revisar permissões e proteger credenciais.
- [ ] Compreender os riscos de comandos como `git reset --hard` e `git push --force`.
- [ ] Explorar o histórico de commits e os mecanismos de recuperação de alterações.
- [ ] Praticar a revisão do conteúdo antes de realizar commits e pushes.
